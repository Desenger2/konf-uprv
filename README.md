# Эмулятор командной строки UNIX-подобной ОС
# Общее описание
Эмулятор представляет собой консольное приложение, имитирующее работу командной оболочки UNIX-подобных операционных систем. Проект реализован на Python и поддерживает:

- Интерактивный режим работы (REPL)
- Выполнение команд из скриптов
- Виртуальную файловую систему (VFS) в памяти
- Базовые и дополнительные команды для навигации и работы с файлами
- Обработку ошибок и валидацию входных данных

# Описание всех функций и настроек
- **Команды эмулятора:**
  - `ls [путь]` - список файлов и директорий
  - `cd [путь]` - смена текущей директории
  - `cat [файл...]` - вывод содержимого файлов
  - `tail [-n число] [файл]` - вывод конца файла
  - `who` - информация о текущем пользователе
  - `exit` - выход из эмулятора
  - `touch [файл...]` - создание пустых файлов или обновление существующих
  - `cp <источник> <назначение>` - копирование файлов
  - `vfs-load <путь>` - загрузка новой VFS из XML
- **Динамическое приглашение** - формат `username@hostname:directory$` с реальными данными ОС и текущем путем в VFS
- **Парсер команд** - поддержка раскрытия переменных окружения (`$HOME`, `$USER`, etc.)
- **Обработка ошибок** - сообщения о неизвестных командах и ошибках выполнения
- **Параметры командной строки**:
  - `--vfs` - путь к физическому расположению VFS
  - `--script` - путь к стартовому скрипту
- **Выполнение скриптов** - выполнение скриптов с командами из файла
- **Остановка при ошибке** - скрипт прерывается при первой ошибке выполнения
- **Отладочный вывод** - отображение всех заданных параметров при запуске
- **Скрипт реальной ОС** - тестирование эмулятора скриптом для реальной ОС
- **Загрузка VFS из XML** - поддержка формата с base64-кодированием бинарных данных
- **Иерархическая структура** - поддержка директорий и файлов с вложенностью
- **Обработка ошибок VFS** - сообщения о проблемах загрузки и неверном формате
- **Интеграция с интерфейсом** - приглашение показывает текущий путь в VFS

# Описание команд для сборки проекта и запуска тестов
  Чтобы запустить проект, можно воспользоваться следующими командами:
- `python Main.py` - запуск без конфигурации
- `python Main.py --script [путь до скрипта]` - запуск со стартовым скриптом
- `python Main.py --vfs [путь до VFS]` - запуск с vfs
- `python Main.py --vfs [путь до VFS] --script [путь до скрипта]` - запуск с vfs и стартовым скриптом
